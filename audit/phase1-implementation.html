Phase 1: SEO/AEO foundation

Implementation summary

Phase 1 implementation only. No deployment, route migration, new content page, category noindex change, hardware consolidation, off-market consolidation or nine-section homepage redesign. Existing Google Sheets writes, Calendly destination, field validation, service-prefill logic and payment instructions remain intact.

  • All six Help articles have a commercial parent and 2–3 related destinations. Four broken links and two self-links were repaired without placeholder articles.
  • Shared service hero now uses the existing descriptive H1 copy visibly; the former hero wording remains as an overview H2. Redundant hidden H1 removed. Footer section headings are H2, with styling retained.
  • Sitemap derives five listing detail URLs from the same data/lookup used by detail pages. Both hardware-store URLs remain self-canonical. Category strategy unchanged.
  • Service schema helpers consolidated; providers and publishers reference the canonical organization. Removed unsupported geo, priceRange, Maps-search sameAs, inferred business address and nonfunctional SearchAction. CollectionPage points to WebSite.
  • Article publication date is optional, never inferred from update date. Current articles emit recorded dateModified only. Visible dates use UTC to prevent date-only values shifting one day in browser time zones.
  • Shared canonical helper standardizes origin/path for generated schema and sitemap; non-www header link corrected. All 53 sitemap pages have the expected canonical in local SSR HTML.
  • Navigation now has a native disclosure button, keyboard-operable links, expanded/control states, Escape handling and mobile focus placement/return. Added skip link, focus outlines and reduced-motion handling, including disabling homepage parallax when requested.
  • Form messages distinguish inquiry, Calendly scheduling, payment uncertainty and Sheets synchronization failure. Calendly messages require matching origin, iframe source and an event URI; duplicate booking events are ignored. Removed the false “no intake forms” assertion.

Approved positioning recorded for the later homepage phase: LOS ANGELES RESTAURANT BROKERAGE & ADVISORY; H1 “Restaurant Transactions, Handled End-to-End.” Supporting copy: Penthouse Advisors helps restaurant owners, buyers, sellers and operators navigate restaurant acquisitions, dispositions, leasing, licensing, permitting and complex transactions throughout Los Angeles County. No hero redesign or positioning rollout in Phase 1.
